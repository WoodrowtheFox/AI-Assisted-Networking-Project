1. Make sure that you have Ookla speedtest for Desktop installed.

2. Once you have that installed go to metrics.py and change line 29 to be your file path.

3. Once that is done you can run it by typing in python -m report (Assuming you are using Windows and have python installed).

4. It will then prompt you to enter how many tries for each IP you would like to do.

5. You will then be asked to enter in the IPS that you would like to add. 

6. Once you have entered at the IPs you want to test type EXIT and wait. 

7. Once it is finished, all of the report files will be in the folder labeled support.
